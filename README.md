=>  Office Task Monitor 

A full-stack real-time office task monitoring system designed to track tasks, users, and progress across teams with live updates and dashboards.

=> Features 

- Create and assign tasks to employees
- Track task status (TODO, IN_PROGRESS, DONE)
- Real-time task updates (no page refresh)
- Live dashboard for managers
- User-based task visibility
- Activity logs for task changes

= = Tech Stack = =

=> Backend
- Java 17
- Spring Boot
- Spring WebSocket
- Spring Data JPA
- MySQL / PostgreSQL

=> Frontend
- React
- JavaScript
- Tailwind CSS
- WebSocket
